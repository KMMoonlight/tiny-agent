# Weekly Report Skill

When writing a weekly report, follow these rules:

## Structure

The report must contain exactly these four sections, in this order:

1. **本周进展** — what was done, one bullet per item, most important first
2. **数据与结果** — concrete numbers, metrics or measurable outcomes; cite the source of each number
3. **问题与风险** — blockers and risks; say "无" if there are none, never omit the section
4. **下周计划** — at most 3 items, each actionable within one week

## Style

- Lead with the outcome, not the process ("完成了 X" not "做了 X 相关工作")
- Every claim must trace back to material gathered in this conversation
  (tool results, notes); never invent progress
- Keep the whole report under 300 Chinese characters
